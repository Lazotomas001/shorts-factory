# Privacy Policy – Shorts Factory Uploader

_Last updated: November 21, 2026_

Shorts Factory Uploader is a private, internal tool operated by Tomas Lazo (lazotomas001@gmail.com).
It is used only to upload original videos that the operator creates to YouTube channels the operator owns.

**What it accesses.** With the operator's own Google sign-in, the tool uses the YouTube Data API to
(1) upload videos and their titles, descriptions, tags and audience settings to the operator's channels, and
(2) read public video statistics for trend research.

**What it stores.** Only an OAuth refresh token for the operator's own channels, kept as an encrypted
GitHub Actions secret. It does not collect, store, sell or share any data about other people or YouTube viewers.

**Third parties.** Data is only exchanged with Google/YouTube through the official API. The tool uses
YouTube API Services; see the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the
[Google Privacy Policy](https://policies.google.com/privacy).

**Revoking access.** Access can be revoked at any time at https://myaccount.google.com/permissions or via
https://security.google.com/settings/security/permissions.
